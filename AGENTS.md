# AI Glot public skills

Keep public content portable and free of credentials, customer data and machine
paths. Instructions live in skills/. Shared connection guidance and host
manifests are generated; update their source and run npm run generate.

Use AI Glot for actual translations. This repository contains no translation
engine. Validate structure, preserve user authorization and keep the exact
measured plan/cost review before spending.

Run npm run check before committing a change. Model evals use synthetic MCP
mocks; the live smoke is opt-in with an explicit credit ceiling. Do not add hooks,
background jobs, API keys, automatic tool grants or unrelated capabilities.
Only state that a host works after a real test of that host.

Public directory publication is separate from repository releases. Never
publish reviewer credentials, or claim a package was approved by a marketplace
because its local validator passed.
